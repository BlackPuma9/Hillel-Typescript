## HW5. Deep Clone

Write a function to recursively copy an object, taking into account nested objects and arrays.

`const original = { a: 1, b: { c: 2 }, d: [3, 4] };`

`const copy = deepClone(original);`

`// original !== copy`

`// original.b !== copy.b`

`// original.d !== copy.d`
